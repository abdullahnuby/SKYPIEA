# تقرير تعديل صفحة SKYPIEA — Alpha 12

## المشكلة التي عالجها الإصدار

كانت النسخة Alpha 11 قد جعلت الصفحة العامة تتمحور حول Beno بدرجة أزاحت وصف SKYPIEA وخدماتها الأساسية. أصلح Alpha 12 هذا الاتجاه بالرجوع إلى بنية صفحة الشركة، لا بمجرد تعديل العناوين.

## ما تم استعادته

- صفحة تعريف الشركة في الواجهة الرئيسية والهوية والرسالة العامة.
- قطاعا الهندسة والتكنولوجيا وبطاقتاهما.
- قسم الخدمات مع تبويب تفاعلي بين القطاعات.
- منهجية العمل، ومميزات الشركة، وقسم «عن SKYPIEA»، ونموذج التواصل عبر WhatsApp.
- العنوان الوصفي وبيانات المشاركة الاجتماعية باسم SKYPIEA بدل تمحور الصفحة حول Beno.

## كيف يظهر Beno الآن؟

- رابع بطاقة داخل الخدمات التكنولوجية.
- قسم منتج مميز يشرح دوره كأداة متخصصة للتسعير الهندسي، ويعرض معاينة توضيحية لا تدّعي أنها تقدير حقيقي.
- زرا تجربة يفتحان نفس المحادثة الحالية ويجهزان سؤالًا مرتبطًا بالسياق دون إرساله تلقائيًا.
- يظل الشات مغلقًا بعد فتح الصفحة إلى أن يختاره الزائر.

## التحقق

- `npm test`: نجحت 18/18 مجموعة اختبارات للمحركات والـ API والمعرفة والإدارة.
- `npm run build`: نجح تدقيق كتالوج الأسعار وقاعدة معرفة الوكيل وبناء ملفات النشر.
- `npm run test:landing`: نجح على الهاتف والكمبيوتر؛ جميع أقسام الشركة موجودة، أربعة خدمات في تبويب التكنولوجيا، قسم Beno واضح كمنتج، تحويل اللغة يعمل، لا يوجد تمرير أفقي، والسؤال يُجهّز دون إرساله تلقائيًا.
- `npm run test:workspace`: نجح على الكمبيوتر والموبايل والوضع الداكن.
- `npm run test:browser`: نجح على الهاتف والكمبيوتر بالوضعين الفاتح والداكن؛ لا أخطاء متصفح، ونجح تعديل كمية بند وإعادة حسابه.
- `npm run test:admin:browser`: نجح اختبار واجهة لوحة الإدارة.
- `npm run check:secrets`: نجح فحص حزم المتصفح.

## ما لم يتغير

لم تتغير محركات الحساب أو كتالوج الأسعار بسبب إعادة تنظيم صفحة الشركة. لا يزال Beno يستخدم محرك الحوار والحساب الحاليين؛ لم تتم إضافة نموذج لغوي خارجي. ولم يتم النشر على GitHub أو Vercel ضمن هذه المهمة.
