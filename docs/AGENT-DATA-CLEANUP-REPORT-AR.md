# تقرير تنظيف بيانات ومعرفة الوكيل BENO — Alpha 8

**التاريخ:** 21 أكتوبر 2026  
**نطاق العمل:** تقليل الضوضاء في مصدر التسعير الذي يراه الوكيل افتراضيًا، مع حفظ الأرشيف، وتوحيد قواعد الحصر والمطابقة.

## سبب تضخم الرقم السابق

كان الكتالوج السابق يحتوي **474 سجلًا نشطًا**؛ منها **291 سجلًا (61.4%)** مستوردة من نشرة يناير 2026، تشمل ماركات ومقاسات وأنواعًا كثيرة لم تكن مرتبطة بأي قاعدة حصر أو بند مستخدم في نماذج المقايسة الحالية. وجودها جميعًا في قائمة المطابقة الافتراضية جعل الرقم كبيرًا من غير فائدة عملية في الحصر المعتاد.

## النتيجة بعد التنظيف

| المقياس | Alpha 7 | Alpha 8 |
|---|---:|---:|
| السجلات المخزنة في الكتالوج التشغيلي | 492 | 201 |
| السجلات النشطة افتراضيًا | 474 | 183 |
| سجلات لها متوسط سعر رقمي موجب | 456 | 165 |
| فجوات أسعار صريحة | 18 | 18 |
| أسعار نشطة قديمة أو غير مؤرخة (>90 يومًا) | 328 | 37 |
| صفوف نشرة يناير خارج المطابقة الافتراضية | 0 | 291 في أرشيف منفصل |

انخفض عدد السجلات النشطة التي يطابق عليها الوكيل تلقائيًا من 474 إلى 183 (**61.4% أقل**). وأصبحت التغطية الرقمية في الكتالوج التشغيلي 90.2% (165/183)، بدل احتساب مئات السجلات التي لا يستخدمها الحصر الحالي. هذه النسبة لا تقيس حداثة السعر أو اعتماده.

## أين ذهبت بيانات النشرة؟

لم تُحذف. جرى نقل جميع سجلات `J26-001` إلى `J26-291` إلى `api/_data/price-book-extended.v1.json`. جميعها موسومة `active=false` و`searchable=false` في الأرشيف حتى لا تظهر ضمن مطابقة الوكيل الافتراضية. يمكن مراجعتها وإعادة إدخال أي عنصر لاحقًا بعد ربطه بوحدة وبند و/أو معدل استهلاك ومراجعة سعره محليًا.

## ما بقي داخل الكتالوج الأساسي؟

- موارد وأسعار البنود الأكثر ارتباطًا بقواعد الحصر الحالية، مع بيانات المصدر والوحدة ونطاق الشمول.
- المصنعيات المحلية المدخلة سابقًا.
- 18 فجوة سعر لم تُملأ تخمينًا.
- مراجع مشتقة معلنة، مع بقاء قواعدها موسومة حتى لا تُعامل كأنها عروض سوق مستقلة.

## قواعد المعرفة التي بقيت كما هي

- 13 مجموعة عمل هندسية، و68 معدل استهلاك مركزيًا، ومرادفات منفصلة حسب التخصص.
- فصل الخامات عن المصنعيات داخل مجموعة العمل الصحيحة، وتطبيق الهالك على التوريدات فقط وفق سياسة كل مورد.
- عدم تحويل السعر بين وحدات غير متوافقة، وعدم تحويل السعر المشتق إلى عرض مورد، وعدم إغلاق فجوة سعر دون مصدر.

## التحقق والحدود

- أُضيفت اختبارات تمنع تسرب صفوف `J26-*` إلى الكتالوج التشغيلي، وتتحقق من بقاء سجلات النشرة الـ291 في الأرشيف.
- يجب أن ينجح `npm test` و`npm run build` و`npm run audit:prices` و`npm run report:gaps` بعد تشغيل التوليد من `scripts/update-prices-2026.cjs`.
- لا يزال 37 سعرًا تشغيليًا قديمًا أو غير مؤرخ و18 فجوة مفتوحة؛ يجب مراجعتها قبل استخدام الناتج كميزانية تنفيذ.
- لم يُنشر الإصدار على Vercel ولم تُرحّل أي قاعدة إنتاج.
