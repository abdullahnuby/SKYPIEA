# SKYPIEA — Engineering & Technology Solutions

Landing Page responsive بهوية SKYPIEA، مبنية بـ HTML وCSS وJavaScript فقط. لا توجد أي مكتبات خارجية مطلوبة ولا قاعدة بيانات؛ يوجد أمر build صغير باستخدام Node.js يجهّز الملفات الثابتة داخل `dist` للنشر.

## المزايا

- واجهة عربية RTL مع تبديل فوري إلى الإنجليزية.
- تصميم متجاوب للموبايل والتابلت وسطح المكتب.
- هوية كحلي وأزرق مع شعار SVG وأيقونة للموقع.
- قطاعان واضحان: الهندسة والتكنولوجيا.
- تبويب تفاعلي لتبديل الخدمات بين القطاعين.
- نموذج طلب خدمة يُجهّز رسالة تحتوي على الاسم ورقم التواصل والقطاع وتفاصيل المشروع ثم يفتح WhatsApp.
- اتصال مباشر عبر الرقم `01550130114` وزر WhatsApp عائم.
- لا يتم تخزين بيانات الزائر على موقع الواجهة الأمامية.

## النشر على GitHub ثم Vercel

1. فك ضغط ملف ZIP على جهازك.
2. أنشئ مستودعًا جديدًا على GitHub، وارفع **محتويات هذا المجلد** بحيث يكون `index.html` في جذر المستودع مباشرة.
3. افتح Vercel، واختر **Add New → Project**، ثم استورد مستودع GitHub.
4. إذا لم يقرأ Vercel الإعدادات من `vercel.json` تلقائيًا، اختر **Other** واستخدم Build Command: `npm run build` وOutput Directory: `dist`.
5. اضغط Deploy. لا تحتاج إلى إضافة Environment Variables أو توصيل قاعدة بيانات.

> تأكد أن `index.html` و`app.js` و`styles.css` و`favicon.svg` ومجلد `assets` موجودة معًا في جذر النشر كما هي داخل الملف المضغوط.

## تعديل رقم التواصل

في `app.js` ابحث عن:

```js
const PHONE_DISPLAY = '01550130114';
const WHATSAPP_NUMBER = '201550130114';
```

الأول لعرض الرقم، والثاني لرابط WhatsApp الدولي. عند تغيير الرقم عدّل القيمتين.

## نقاط قبل الإطلاق

- نموذج التواصل يفتح رسالة WhatsApp جاهزة، ويحتاج الزائر إلى الضغط على إرسال من داخل WhatsApp؛ لا تُخزّن البيانات ولا تُرسل تلقائيًا في الخلفية.
- روابط الموقع والبريد وحسابات التواصل الأخرى لم تُضف لعدم توفر بيانات مؤكدة لها.
- يحمّل الموقع خطّي Alexandria وMontserrat من Google Fonts؛ إن لم يتوفرا، ستُستخدم الخطوط البديلة المعرفة في CSS.
- التحقق من تسجيل SKYPIEA كعلامة تجارية أمر منفصل عن نشر الموقع.
