# تقرير تحسين ويجت Beno — Alpha 13

## الهدف
تطوير الويجت العائمة نفسها داخل صفحة SKYPIEA حتى تصبح نقطة تعريف أولية بالمساعد، مع بقاء صفحة الشركة وخدماتها هي التجربة الرئيسية. لا يفتح الترحيب مساحة المحادثة الكاملة تلقائيًا.

## ما تم تنفيذه
- إطلاق بصري جديد: شارة B، مؤشر حالة، اسم Beno، ووصف «مساعد التسعير الهندسي»، مع تدرج أزرق داكن وظلال وحدود وحالات تركيز واضحة.
- رسالة ترحيب تظهر بعد نحو 1.9 ثانية عند أول زيارة للجلسة: «أهلاً بيك في SKYPIEA» وتقديم Beno ودوره في تقدير تكلفة البناء وتنظيم المقايسة وتوضيح نواقص الكميات والأسعار.
- زران واضحان: «جرّب Beno» لفتح مساحة المحادثة الحالية، و«مش دلوقتي» لإخفاء الرسالة دون فتح المحادثة. زر إغلاق مستقل ودعم لوحة المفاتيح والتركيز.
- منع تكرار الترحيب في جلسة التصفح ذاتها، وإخفاؤه عند بدء المحادثة أو بعد انتقال الزائر إلى أسفل الصفحة.
- تصغير زر الويجت إلى أيقونة عند التمرير لتقليل تغطية محتوى الصفحة.
- استجابة للموبايل مع مراعاة safe-area والارتفاع المتاح، مع دعم تقليل الحركة حسب تفضيلات النظام.
- إعداد التضمين في صفحة الشركة: `data-autoopen="false" data-welcome="true"`؛ يمكن تعطيل الترحيب في أي تضمين باستخدام `data-welcome="false"`.
- الحفاظ على صفحة SKYPIEA باعتبارها صفحة شركة: قطاعات الهندسة والتكنولوجيا، والخدمات والمنهجية والتعريف بالشركة والتواصل؛ Beno منتج بارز ضمن الخدمات التكنولوجية وليس بديلًا عن الشركة.

## التحقق
- `npm test`: نجحت جميع مجموعات اختبارات Node وعددها 18 من 18.
- `npm run build`: نجح تدقيق كتالوج الأسعار وقاعدة معرفة الوكيل والبناء الثابت.
- `python3 tests/landing-page-smoke.py` / `npm run test:landing`: نجح على الهاتف والكمبيوتر. الترحيب يظهر، ولا يفتح الشات وحده، ويمكن بدء المحادثة أو إخفاء الترحيب. لا تمرير أفقي ولا أخطاء متصفح.
- `npm run test:browser`: نجح على الهاتف والكمبيوتر بالوضعين الفاتح والداكن؛ الحساب وتعديل الكمية والإغلاق بلوحة المفاتيح عملت دون أخطاء JavaScript.
- `npm run test:workspace`: نجح على الكمبيوتر والموبايل بالوضعين المدعومين، مع اختبار مساحة العمل ومحرر الرسائل ولوحة سياق المشروع.
- `npm run test:admin:browser`: نجح اختبار لوحة الإدارة.
- `npm run check:secrets`: نجح فحص أنماط الأسرار في حزم العميل.
- `npm run audit:prices:all`: نجح تدقيق سلامة كتالوج الأسعار وقاعدة معرفة الوكيل.
