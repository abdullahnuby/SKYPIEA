# تقرير شامل: نماذج وكيل التسعير المحلي — شقق وعمارات

هذا التقرير هو **مواصفة تشغيلية كاملة** لتدريب وكيل تسعير بدون LLM. يعتمد على محرك قواعد وقاعدة بيانات معدلات، بحيث يختار النظام النموذج الصحيح تلقائياً حسب نوع الخدمة وحالة الاستلام، ثم يحسب الكميات والتكلفة بمعادلات ثابتة.

## 1) المبدأ العام

الوكيل لا يفهم “التصميم”، بل يفهم **حالة العقار والمرحلة المطلوبة**:

```text
مدخلات العميل → تحديد النموذج → اختيار البنود → حساب الكميات → تطبيق الأسعار → عرض السعر
```

كل بند له:

- كود.
- اسم.
- وحدة قياس.
- شرط الظهور.
- معادلة الكمية.
- سعر المادة.
- سعر المصنعية.
- نسبة هالك.
- نطاق التطبيق: شقة أو عمارة أو كلاهما.

## 4) معادلات أساسية

| الكمية | المعادلة |
|---|---|
| مساحة الحوائط والأسقف | `wall_area = apartment_area * wall_factor` |
| مساحة الأرضيات | `floor_area = apartment_area * floor_factor` |
| كمية المحارة | `plaster_qty = apartment_area * 2.20` |
| أسمنت المحارة | `cement_bags = apartment_area * 0.30` |
| رمل المحارة | `sand_m3 = apartment_area * 0.07` |
| كمية المعجون | `putty_kg = paintable_area * putty_rate` |
| كمية البلاستيك | `paint_liters = paintable_area * paint_rate` |
| كمية الحديد | `steel_kg = built_area * steel_rate_per_m2` |
| كمية الخرسانة | `concrete_m3 = built_area * concrete_rate_per_m2` |
| سعر البند | `(qty * material_price * waste_factor) + (qty * labor_price)` |
| سعر المتر | `total_cost / total_built_area` |

## 11) النموذج 6: عمارة سكنية من الصفر

### شرط التفعيل

```text
property_type = residential_building

```

### مدخلات النموذج

```text
مساحة الأرض
المسطح لكل دور
عدد الأدوار
عدد الشقق في الدور
بدروم: نعم / لا
نوع التربة
المياه الجوفية
نوع المقايسة
مستوى التشطيب
```

### المراحل

1. حفر وردم وإحلال.
2. لبشة وقواعد وعزل.
3. هيكل خرساني لكل دور.
4. سلالم ومباني.
5. محارة داخلية وخارجية.
6. شبكات عامة.
7. تشطيب الوحدات.
8. أسطح وواجهات ومداخل.
9. مصاعد وخدمات مشتركة.
10. تنظيف وتسليم.

### معدلات الإنشاء

| البند | وحدة | المعدل | المعادلة |
|---|---:|---:|---|
| حفر قواعد | م³ | 0.12 | `built_area * 0.12` |
| ردم | م³ | 0.06 | `built_area * 0.06` |
| إحلال زلط | م³ | 0.10 | `built_area * 0.10` |
| لبشة | م³ | 0.03 | `built_area * 0.03` |
| خرسانة قواعد | م³ | 0.08 | `built_area * 0.08` |
| حديد قواعد | كجم | 8 | `built_area * 8` |
| خرسانة هيكل | م³ | 0.30 | `built_area * floors * 0.30` |
| حديد هيكل | كجم | 80 | `built_area * floors * 80` |
| سلالم | م² | 0.06 | `built_area * floors * 0.06` |
| طوب | قطعة | 25 | `built_area * 25` |
| محارة داخلية | م² | 2.20 | `built_area * 2.20` |
| محارة خارجية | م² | 0.55 | `built_area * 0.55` |
| عزل أسطح | م² | 1.00 | `roof_area * 1.00` |

المعدلات الشائعة للخرسانة المسلحة تقارب 0.30–0.40 م³/م²، والحديد 60–100 كجم/م²، وتتأثر بعدد الأدوار ونوع السقف والقواعد. 

### مثال تدريبي

```text
مساحة الأرض = 300 م²
المسطح لكل دور = 220 م²
عدد الأدوار = 5
بدروم = لا
عدد الشقق في الدور = 2
مستوى التشطيب = لوكس
```

```text
إجمالي المسطح = 220 × 5 = 1,100 م²

خرسانة قواعد = 1,100 × 0.08 = 88 م³
حديد قواعد = 1,100 × 8 = 8,800 كجم = 8.8 طن

خرسانة هيكل = 1,100 × 5 × 0.30 = 1,650 م³
حديد هيكل = 1,100 × 5 × 80 = 440,000 كجم = 440 طن

طوب = 1,100 × 25 = 27,500 قطعة
محارة داخلية = 1,100 × 2.20 = 2,420 م²
محارة خارجية = 1,100 × 0.55 = 605 م²

عدد الشقق = 5 × 2 = 10 شقق
تشطيب الوحدات = 10 × تكلفة تشطيب شقة 110 م²
```

## 13) النموذج 8: عمارة مختلطة

### المنطق

```text
المسطح السكني = عدد الشقق × مساحة الشقة
المسطح التجاري = مساحة المحلات
إجمالي المسطح = سكني + تجاري + خدمات
```

### مثال

```text
دور أرضي تجاري = 200 م²
4 أدوار سكنية × 200 م² = 800 م²
إجمالي المسطح = 1,000 م²
عدد الشقق = 8
```

```text
خرسانة هيكل = 1,000 × 5 × 0.30 = 1,500 م³
حديد هيكل = 1,000 × 5 × 80 = 400,000 كجم
تشطيب المحلات = 200 م² × معامل تجاري
تشطيب الشقق = 8 × تكلفة شقة 100 م²
```

## 15) النموذج 10: تشطيب عمارة قائمة

### المنطق

```text
تكلفة المشروع = تكلفة تشطيب كل وحدة + المرافق العامة + الواجهات + الأسطح
```

### البنود

- تشطيب كل شقة حسب حالتها.
- تشطيب المداخل والسلالم.
- تشطيب الواجهات.
- عزل الأسطح.
- شبكات المياه والصرف والكهرباء العامة.
- مصاعد إذا لم تكن موجودة.
- تنظيف وتسليم.

### مثال

```text
عمارة 5 أدوار
10 شقق × 110 م²
حالة كل شقة = محارة
```

```text
تشطيب كل شقة = 110 م² × سعر تشطيب المحارة
إجمالي الوحدات = 10 × تكلفة الشقة
الواجهات = 1,100 × 0.55 = 605 م²
الأسطح = 220 م² × 1.00 = 220 م²
```

### شكل المخرج

```text
التكلفة الإجمالية = مجموع البنود × معامل التشطيب × (1 + إشراف + مخاطر + ربح)
سعر المتر = التكلفة الإجمالية ÷ 120
```

## 18) مثال كامل: عمارة 5 أدوار

### المدخلات

```text
المسطح لكل دور = 220 م²
عدد الأدوار = 5
عدد الشقق في الدور = 2
بدروم = لا
التربة = طبيعية
المقايسة = تسليم مفتاح
التشطيب = لوكس
```

### الحساب

```text
إجمالي المسطح = 1,100 م²
عدد الشقق = 10

خرسانة قواعد = 88 م³
حديد قواعد = 8.8 طن
خرسانة هيكل = 1,650 م³
حديد هيكل = 440 طن
طوب = 27,500 قطعة
محارة داخلية = 2,420 م²
محارة خارجية = 605 م²
عزل سطح = 220 م²

تشطيب الوحدات = 10 × تكلفة شقة 110 م²
```

### شكل العرض

```text
تكلفة الإنشاء العام = X جنيه
تكلفة تشطيب الوحدات = Y جنيه
تكلفة المرافق والواجهات = Z جنيه
الإجمالي = X + Y + Z + إشراف + مخاطر + ربح
سعر المتر = الإجمالي ÷ 1,100
```

## 19) قواعد الوكيل النهائية

```text
إذا كان نوع الخدمة = شقة:
    لا تحسب حفر أو قواعد أو هيكل.
    اسأل عن حالة الاستلام.
    اختر النموذج المناسب: طوب / محارة / محارة + تمديدات / جاهزة للدهان / جزئي.

إذا كان نوع الخدمة = عمارة من الصفر:
    ابدأ من الحفر والقواعد.
    احسب الهيكل لكل دور.
    احسب المرافق العامة مرة واحدة.
    احسب تشطيب كل وحدة على حدة.
    اجمع التكلفة واقسمها على إجمالي المسطح.

إذا كان نوع الخدمة = عمارة خرسانة فقط:
    أوقف كل بنود التشطيب النهائي.

إذا كان نوع الخدمة = تشطيب عمارة قائمة:
    ابدأ من حالة كل وحدة.
    أضف الواجهات والأسطح والمرافق العامة.

إذا كان البدروم موجود:
    أضف حفر بدروم + نزح + لبشة + حوائط + عزل.

إذا كانت التربة طينية أو المياه قريبة:
    ارفع معامل الحفر والإحلال والعزل والمخاطر.
```

## 20) خطة التدريب العملية

1. أدخل 20 حالة شقة حقيقية: طوب، محارة، محارة + تمديدات، جاهزة للدهان، جزئي.
2. أدخل 10 عمارات سكنية بعدد أدوار ومساحات مختلفة.
3. أدخل 5 عمارات تجارية و5 مختلطة.
4. قارن مخرجات النظام بأسعار مقاولين فعليين في الأقصر.
5. عدّل المعدلات والمعاملات حتى يصبح الفرق المقبول ضمن نطاق محدد.
6. حدّث الأسعار دورياً من لوحة التحكم.
7. اجعل النظام يعرض دائماً: “تسعير تقديري قابل للتعديل بعد المعاينة.”

هذا التقرير يكفي كأساس لبناء الوكيل: **نماذج منفصلة، بنود مشروطة، معادلات كمية ثابتة، وأسعار قابلة للتحديث**.
